# Research notes

Analyses that inform the [specification](../SPEC.md) but are not part of it:

* comparisons with related tools (`zfs_revert`, `zdb`, Klennet ZFS Recovery, UFS Explorer, ReclaiMe, `zfs-fuse`);
* `ondisk-notes.md` — on-disk structure notes with references to OpenZFS source, per structure;
* recorded real-world recovery scenarios that the fixture-pool test suite should reproduce.

Bilingual files follow the `NAME.md` / `NAME.uk.md` convention.
